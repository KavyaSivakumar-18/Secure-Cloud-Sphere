How to Enable Live AWS Monitoring

To enable real-time telemetry from your AWS account, configure your IAM credentials inside the backend backend/.env file:

AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
AWS_REGION=ap-south-1
S3_BUCKET_NAME=my-aws-production-bucket
PORT=5000

Security Reminder: Never hard-code credentials in frontend JavaScript or commit .env files to version control. Credentials are read exclusively by the Node.js backend using AWS SDK v3.
